# UIモック（参照用）

Claude（claude.ai）のデザインキャンバスで作成したUIモックの書き出し。
**見た目・画面構成・文言・操作の流れの参照用**であり、コードとしてそのまま流用しない。
仕様の正は `../plan.md`（企画・構成・開発計画）。

## ファイル形式の注意
- 各 `screens/*.dc.html` はキャンバス専用の「Design Component」形式。ブラウザで直接開いても正しく表示されない
- レイアウトとスタイルはすべてインラインstyleに書かれているので、寸法・色・余白・文字サイズはそこから読み取る
- `<x-dc>` `<helmet>` `<sc-for>` `<sc-if>` `{{...}}` と、末尾の `class Component extends DCLogic` はモック用の独自記法。実装ではNext.js（React）のコンポーネント、状態管理、リストのmapに置き換える
- 末尾のスクリプト内の配列（オーダー、品目など）はサンプルデータ。データ構造の参考にしてよい
- `[ホテル名]` `[料金]` はプレースホルダ。人名・数値もすべてサンプル

## 画面遷移（モック内のリンク）
- 現場スマホ: 下部タブ オーダー／AIに相談／通知
- 管理PC: 左メニュー ホーム／オーダー／施設・営業情報／品目・担当設定／館内案内・マニュアル／未回答の質問／引き継ぎ・クレーム履歴
- 経営: 上部タブ 担当範囲とコスト／指示とガードレール／外部連携／変更履歴
- 管理PCのメニューは、ログインしたメンバーの権限によって表示を出し分ける（plan.md 4.8）

## デザインの基本
- フォント: 見出しのホテル名は Shippori Mincho B1（600）、それ以外は Zen Kaku Gothic New（400 / 500 / 700）。Google Fonts
- 色
  | 用途 | 値 |
  |---|---|
  | 背景 | #F5F3EE |
  | 面（カード） | #FFFFFF |
  | 文字 | #1D2528 |
  | 補助の文字 | #5B6468 |
  | 線 | #E2DED6（入力欄は #D8D3CA） |
  | 主色（深緑） | #1F5C5A ／ 薄い地 #E3EEEC |
  | 注意（琥珀） | 文字 #9A5B0B ／ 薄い地 #F7ECDC |
  | 警告（赤） | 文字・枠 #A3261D ／ 薄い地 #F8E4E1 |
  | 濃い面（ナビ等） | #1D2528 ／ #2F3B3F |
  | 重み・モデル | 軽・Nano #E3EEEC/#1F5C5A、中・Super #D5E3F0/#1F4E79、重・Ultra #1F4E79/#FFFFFF |
- 角丸: カード 12〜16px、ボタン 8〜10px、チップ 20px以上
- タップ領域: 44px以上（現場スマホの主要ボタンは52px）
- アイコン: 線のSVG（stroke-width 1.8〜2）。絵文字は使わない
