# 動画編集の指示書（Yadori デモ・英語・3分以内）

編集する人（あなた、または編集を頼む相手）向け。素材は2026-10-17に収録した画面録画（1本）。台本は `script.md`、直す点の一覧は `editing-notes.md`。

## 1. 目標と制約

- 完成: **3:00以内**（目標 2:50〜2:58）、英語ナレーション＋英語字幕、**音楽なし**（または著作権フリーのみ）
- 提出先: YouTubeに公開 → Devpostに動画URLを記入。審査員は動画だけで判断することがあるので、**画面の文字が読めること**を最優先にする
- 書き出し: MP4（H.264）、1920×1080、30fps、音声はAAC。YouTubeの「公開」または「限定公開」でアップし、ログアウトした状態でURLが開くことを確認する

## 2. 素材の前提

- 収録は1本の連続した画面録画。ゲストの画面は幅が狭い（スマホ幅）ので、拡大して見せる
- 収録中に操作した順: 場面1 → 2 → 3 → 4 → 5 → 6（台本どおり）。ただし場面2は読み取りを**2回**やっている（1回目は失敗）
- 録画の頭と終わりに、録画の開始・停止の操作が映っている可能性がある。トリミングする

## 3. 場面ごとの編集指示

目標の尺は、ナレーションの読みと画面の動きを合わせた目安。素材の長さに応じて前後してよい。

| 場面 | 目標の尺 | 使う映像 | カット・加工 |
|---|---|---|---|
| 1 Problem | 0:00–0:20 | トップページ → ゲストの画面（1203号室） | トップページは5秒ほど見せる。ゲスト画面へ移るところで話を切り替える |
| 2 Seasonal switch | 0:20–1:00 | 管理PCでPDFを選ぶ → 読み取り → 確認画面 → 承認 → ゲスト2人の質問と回答 | **1回目の読み取り（Parkingの行が出た確認画面）は全部カット**。2回目（新しい施設1件、重なり2件）を使う。読み取り待ち10〜20秒と、AIの応答待ちは早送りかカット |
| 3 Special notice | 1:00–1:20 | 管理PCで特記事項を追加 → ゲストに質問 → 回答と根拠の表示 | 入力は等速。回答の下の「Includes the Yukimi Onsen special notice」を2秒ほど止めて見せる |
| 4 Orders | 1:20–1:55 | ゲストの注文 → 選択欄 → Place request → スタッフのスマホ → On my way → Delivered → ゲスト画面の完了 | 画面の切り替えはカットでつなぐ。選択欄でスクロールする部分は短くする |
| 5 Management | 1:55–2:45 | `/manage`（成果・取りこぼし・AIの仕事の表）→ モデルの見直し（試験運用の選択） | 成果の最上部は止めて見せたい（素材ではスクロールで流れている。撮り直すか、静止画で数秒保持）。長い表はスクロールを速めず、読めるところで止める |
| 6 Close | 2:45–3:00 | トップページ（3つの画面への入口） | 最後の2秒で止める。ロゴや名前のテロップ（Yadori）を入れてもよい |

### 画面の見せ方

- ゲスト画面とスタッフのスマホ画面は、画面の中央の細い部分だけを**約150%に拡大**する（またはトリミング）。管理PCと経営画面は全体を見せる
- 大事な箇所（回答の下の根拠の表示、承認ボタン、Delivered）には、**細い枠か短い矢印**を1〜2秒出す。派手な動きは避ける
- 場面の切り替えは**短いクロスフェード（0.3秒前後）**かカット。凝らない

## 4. ナレーション

- 台本の英文は `script.md` にあり、各場面の英文をそのまま読む（約420語、ゆっくり読んで3分弱）
- 話す速さは1分あたり約140語を目安にする。画面の操作が終わってから説明を始めない。**操作と同時に話す**
- 録音は静かな部屋で。読み間違いは撮り直さず、その文だけ録り直してつなぐ
- 数字は収録した画面に合わせる（`/manage` の「AIで完結した件数」「浮いた人の対応時間」「AIの実費」）。素材の画面では、約9,400件・約500時間・約¥2,500（台本の「over nine thousand requests」「about five hundred staff hours」「a few thousand yen」と合う）
- 注意: 場面3のナレーションは「expires on its own」。特記事項は今日いっぱいで終わる設定なので、言い方は「it ends on its own at the end of the day」に直す

## 5. 字幕

- 英語のみ。ナレーションの英文をそのまま使い、**1行あたり約40文字・2行まで**に分ける
- 場面ごとの見出し（左下に小さく出す）: Seasonal switch / Special notice / Orders / Management
- フォントは読みやすいサンセリフ。背景に半透明の黒帯を敷く

## 6. 差し替え・撮り直しの候補

`editing-notes.md` の表のうち、次を直す場合は追加で撮る（撮り直しの操作は私がやる。画面録画はあなた）。

- 場面5の「今月の成果」の最上部（先頭で数秒止めた映像）
- 場面3: 台本どおり「until 18:00」にしたい場合
- 場面4: Check status → 5 min（状況の確認）を入れたい場合
- 配達完了の自動メッセージの品名の区切り（表記を直してから撮る）

## 7. 仕上げのチェックリスト

- [ ] 全体が3:00以内
- [ ] 1回目の読み取り（Parkingの行）が映っていない
- [ ] 吹き出しが二重に出ている場面が映っていない
- [ ] 画面上の英語がすべて読める（拡大・停止を使った）
- [ ] 日本語（年/月/日の入力欄など）が映っていない
- [ ] ナレーションの数字が画面の数字と合っている
- [ ] 音楽・効果音を使っていない（使うなら著作権フリー）
- [ ] 字幕に誤字がない
- [ ] YouTubeにアップし、ログアウトした状態で再生できる
- [ ] 動画のURLを控え、Devpostの記入に使える

## 8. 納品するもの

- 完成動画（MP4）とYouTubeのURL
- 字幕ファイル（SRT）があれば添付する（YouTubeに英語字幕としてアップできる）
- 使った素材と台本の最終版（修正した場合）を `docs/demo/en/` に置く
