# デモ・検証用の資料

管理PC「館内の情報」→「資料」で読み取らせる資料です（`docs/002_facility_master_design.md`）。

## 使い方

1. `npm run dev` で起動し、`/staff/login` で管理者（田中）としてログインする
2. `/admin/knowledge/sources` を開き、ファイルを選んで「読み取る」（`.txt` は文章欄に貼り付けてもよい）
3. 確認画面で、新しい施設・新しい項目・期間の重なりを確かめて「この内容で承認」
4. 施設の画面（`/admin/knowledge/<施設>`）で案内している内容を確認し、ゲスト画面（`/guest/R-1203` は滞在中、`/guest/R-1503` は来月）で質問する

読み取りは Token Factory を呼ぶ（`LLM_MODE=nebius`）。`LLM_MODE=mock` では冬季営業のお知らせだけ決まった結果を返す。試したあとは「資料」の一覧から削除すると値も消える（新しく作られた施設は残る）。
